# mind-map

Interactive mind map for organizing information through linked nodes of text, images, and links - for learners, teachers, and presenters.

Built with Vite + React 19 + TypeScript. Planned: React Flow for the canvas, Material UI for components. Deployed to GitHub Pages.

## Commands

- Dev server: `npm run dev` (http://localhost:5173)
- Build: `npm run build`
- Preview: `npm run preview`
- Lint: `npm run lint`

No test or Verify command configured yet - run `/tests` or `/ci` when ready.
